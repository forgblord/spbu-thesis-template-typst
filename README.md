# Шаблон ВКР СПБГУ в Typst

Данный репозиторий содержит сырой шаблон для оформления ВКР в соответствии с тербованиями СПБГУ.
Помимо самой ВКР, есть наработка по шаблону презентации.

Структура проекта:

- `main-content.typ` задает стили для основного текста
- `titlepage.typ` задает стили титульной страницы
- `example.typ` показывает пример использования для написания ВКР
- `presentation.typ` задает стили презентации + содержит примеры
- `sources.bib` содержит entries для библиографии, использованные в `example.typ`

Директории:

- `icons/` содержит картинки с символикой спбгу
- `images/` содержит ресурсы, использованные в `example.typ`
- `pres-assets/` содержит ассеты для презентации
- `render-samples/` содержит скомпилированные в пдф `example.typ` и `presentation.typ`
- `unused/` содержит неиспользуемые файлы, которые все равно хочется оставить
